🎮 Roblox'ta Kombolu Kılıç Sallama Animasyonu

Lua programlama ile profesyonel oyun mekaniği oluşturmayı öğrenin!

Ders İçeriği

Bu derste, Roblox Studio kullanarak kombolu bir kılıç savaş sistemi oluşturacaksınız. Oyuncular art arda tıklayarak farklı animasyonlar tetikleyebilecek!

✨ Öğrenecekleriniz

  • Roblox Studio'da animasyon kullanımı
  • Lua programlama temelleri
  • Kombo sistemi mantığı
  • Mouse tıklama algılama
  • Cooldown (bekleme) sistemi

Adım 1: Kılıç Aracını (Tool) Hazırlama

Öncelikle Roblox Studio'da bir kılıç nesnesi oluşturalım:

  1. Roblox Studio'yu açın
  2. Workspace'e sağ tıklayın → Insert Object → Tool
  3. Tool'u "ComboSword" olarak adlandırın
  4. Tool içine Part ekleyin ve "Handle" olarak adlandırın (zorunlu!)
  5. Handle'ı kılıç şeklinde boyutlandırın

Adım 2: Animasyonları Yükleme

Kılıç sallama animasyonlarınızı hazırlayın veya Roblox'un ücretsiz animasyonlarını kullanın:

-- Animasyon ID'lerini buraya yazın
local ANIMASYON_1 = "rbxassetid://YOUR_ANIM_ID_1"
local ANIMASYON_2 = "rbxassetid://YOUR_ANIM_ID_2"
local ANIMASYON_3 = "rbxassetid://YOUR_ANIM_ID_3"

💡 İpucu: Roblox Animation Editor kullanarak kendi animasyonlarınızı oluşturabilir veya Toolbox'tan hazır animasyonları kullanabilirsiniz!

Adım 3: Ana Script (LocalScript)

Tool'un içine bir LocalScript ekleyin ve aşağıdaki kodu yazın:

-- ComboSword LocalScript
local tool = script.Parent
local handle = tool:WaitForChild("Handle")

-- Oyuncu ve karakter referansları
local player = game.Players.LocalPlayer
local character = player.Character or player.CharacterAdded:Wait()
local humanoid = character:WaitForChild("Humanoid")

-- Animasyon ayarları
local animasyonlar = {
    "rbxassetid://89289879",  -- Slash animasyonu 1
    "rbxassetid://186934658", -- Slash animasyonu 2
    "rbxassetid://186934910"  -- Slash animasyonu 3 (finisher)
}

local yuklenenAnimasyonlar = {}
local mevcutKombo = 0
local animasyonOynuyor = false
local cooldownSuresi = 0.5
local komboResetSuresi = 1.5
local sonVurusZamani = 0

-- Animasyonları önceden yükle
for i, animId in ipairs(animasyonlar) do
    local animasyon = Instance.new("Animation")
    animasyon.AnimationId = animId
    yuklenenAnimasyonlar[i] = humanoid:LoadAnimation(animasyon)
end

-- Kombo sıfırlama fonksiyonu
local function komboSifirla()
    wait(komboResetSuresi)
    if tick() - sonVurusZamani >= komboResetSuresi then
        mevcutKombo = 0
        print("Kombo sıfırlandı!")
    end
end

-- Kılıç sallama fonksiyonu
local function kilicSalla()
    if animasyonOynuyor then
        return -- Animasyon devam ediyorsa yeni vuruş yapma
    end
    
    animasyonOynuyor = true
    sonVurusZamani = tick()
    
    -- Komboyu ilerlet
    mevcutKombo = mevcutKombo + 1
    if mevcutKombo > #animasyonlar then
        mevcutKombo = 1
    end
    
    print("Kombo " .. mevcutKombo .. " oynatılıyor!")
    
    -- Animasyonu oynat
    local animTrack = yuklenenAnimasyonlar[mevcutKombo]
    animTrack:Play()
    
    -- Hasar verme (opsiyonel)
    hasarVer()
    
    -- Animasyon bekleme
    wait(animTrack.Length * 0.7) -- Animasyonun %70'i tamamlanınca yeni vuruşa izin ver
    animasyonOynuyor = false
    
    -- Kombo reset timer'ı başlat
    spawn(komboSifirla)
end

-- Hasar verme fonksiyonu
function hasarVer()
    local hasarMiktari = 10
    local hasarMenzili = 5
    
    -- Kılıcın ucundan raycast yap
    local origin = handle.Position
    local direction = (handle.CFrame * CFrame.new(0, 0, -hasarMenzili)).Position - origin
    
    local raycastParams = RaycastParams.new()
    raycastParams.FilterDescendantsInstances = {character}
    raycastParams.FilterType = Enum.RaycastFilterType.Blacklist
    
    local rayResult = workspace:Raycast(origin, direction, raycastParams)
    
    if rayResult then
        local hit = rayResult.Instance
        local dusman = hit.Parent
        if dusman:FindFirstChild("Humanoid") and dusman ~= character then
            dusman.Humanoid:TakeDamage(hasarMiktari)
            print("Hasar verildi: " .. hasarMiktari)
        end
    end
end

-- Mouse tıklama olayı
tool.Activated:Connect(function()
    kilicSalla()
end)

-- Tool kuşanıldığında
tool.Equipped:Connect(function()
    print("Kılıç kuşanıldı! Kombo sistemine hazır.")
    mevcutKombo = 0
end)

-- Tool çıkarıldığında
tool.Unequipped:Connect(function()
    print("Kılıç çıkarıldı.")
    mevcutKombo = 0
    animasyonOynuyor = false
    
    -- Tüm animasyonları durdur
    for _, animTrack in ipairs(yuklenenAnimasyonlar) do
        animTrack:Stop()
    end
end)

Adım 4: Ses Efektleri Ekleme (Opsiyonel)

Daha gerçekçi bir deneyim için ses efektleri ekleyelim:

-- Ses efektleri için Handle içine Sound objesi ekleyin
local sesEfekti = handle:FindFirstChild("SwingSound")
if not sesEfekti then
    sesEfekti = Instance.new("Sound")
    sesEfekti.Name = "SwingSound"
    sesEfekti.SoundId = "rbxassetid://12222030" -- Kılıç sallama sesi
    sesEfekti.Volume = 0.5
    sesEfekti.Parent = handle
end

-- kilicSalla fonksiyonu içinde, animasyon oynatmadan önce:
if sesEfekti then
    sesEfekti:Play()
end

Adım 5: Test ve İyileştirmeler

✅ Test Kontrol Listesi:

  • Kılıcı envantere ekleyin ve kuşanın
  • Sol fare tuşuyla tıklayarak animasyonları test edin
  • Kombo sisteminin 1-2-3 şeklinde çalıştığını doğrulayın
  • Bekleme süresinden sonra kombonun sıfırlandığını kontrol edin
  • Hasar verme mekanizmasını test edin (başka bir karakter ekleyin)

🚀 İyileştirme Önerileri:

  • Parçacık Efektleri: Handle'a ParticleEmitter ekleyerek kılıç izleri oluşturun
  • Kamera Sallanması: Vuruş anında kamera efekti ekleyin
  • Kombo Göstergesi: ScreenGui ile ekranda kombo sayacı gösterin
  • Kritik Vuruş: Son kombo vuruşunda 2x hasar verin
  • Animasyon Çeşitlendirme: Daha fazla animasyon ekleyerek kombonuzu genişletin

📚 Ek Kaynaklar ve İpuçları

Faydalı Roblox API'ları:

  • Humanoid:LoadAnimation() - Animasyon yükleme
  • Tool.Activated - Tıklama algılama
  • workspace:Raycast() - Çarpışma tespiti
  • tick() - Zaman ölçümü
  • spawn() - Asenkron fonksiyon çalıştırma
